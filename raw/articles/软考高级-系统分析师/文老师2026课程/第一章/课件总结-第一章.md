## 一、计算机系统概述与层次结构

### 1. 三层分层模型（自上而下）

计算机系统层次图

2. **系统层（系统软件）**
    
    - 语言处理程序：编译程序、汇编程序、解释程序（翻译高级 / 汇编语言为机器码）
    - 操作系统：管理软硬件资源，衔接硬件与上层软件

(2) **系统层**：操作系统管理硬件资源，语言处理程序做代码翻译

### 2. 计算机五大硬件组件

1. **CPU**：核心运算单元，完成算术、逻辑运算与整机控制
2. **存储器**：
    
    - 内存（主存）：速度快、容量小，临时存程序 / 数据；分 RAM（断电丢数据，DRAM/ SRAM）、ROM（断电保存，BIOS、微程序控制存储器）
    - 外存（辅存）：容量大、速度慢，长期持久存储（硬盘、SSD、光盘、磁带）
    
3. **输入设备**：录入原始数据、控制命令
4. **输出设备**：输出运算结果
5. 外设：输入 + 输出设备统称外设

### 3. 软件分类

- **系统软件**：操作系统、编译 / 汇编 / 解释器、驱动、固件（EPROM/EEPROM）
- **应用软件**：面向业务、用户自行开发使用的程序

## 二、数据校验码（两大必考纠错检错码）

### 1. CRC 循环冗余校验码

1. 原理：基于生成多项式 G (x)，模 2 除法（无进位、无借位异或除法）
2. 计算步骤：
    
    ① 根据 G (x) 阶数 r，原始信息后补 r 个 0
    
    ② 用二进制 G (x) 对应串做模 2 除，得到 r 位余数；不足 r 位左侧补 0
    
    ③ 原始串拼接余数，得到完整 CRC 校验码
3. 校验规则：接收方用同一 G (x) 模 2 除，余数全 0 无错，否则传输出错；收发双方必须使用相同生成多项式
4. 能力：只能检错，**无法纠错**

### 2. 海明码（可检错 + 单比特纠错）

1. 核心公式：\(2^k -1 \ge n+k\)
    
    - n：数据位数量；k：校验位数量；满足公式才能完成单错纠错
    
2. 编码规则：
    
    ① 整体位编号从 1 开始，**校验位放在 2⁰、2¹、2²… 位置（1、2、4、8、16…）**
    
    ② 每一个数据位编号拆分为二进制，对应编号包含的校验位共同校验该数据位
    
    ③ 所有对应位异或计算得到每一位校验位值
3. 纠错流程：
    
    接收端分组异或所有校验覆盖位，得到二进制出错编号；对应编号比特取反即可修正错误

## 三、存储系统（本章分值最高模块）

分级存储体系设计目标：解决**速度、容量、成本**三者矛盾，层级：CPU 寄存器 → Cache → 主存 RAM → 辅存硬盘 / 光盘

### （一）主存分类

1. RAM 随机存取存储器
    
    - SRAM：高速、贵，用于 Cache；断电丢失数据
    - DRAM：低速、廉价，用作内存；断电丢失数据
    
2. ROM 只读存储器：断电数据保留，用于 BIOS、字符发生器、微程序控制器

### （二）辅存：机械硬盘 HDD

![[74a3a6aa6ae6487f-0c2ca0de827f4707~tplv-be4g95zd3a-448x448.jpeg|image]]

磁盘物理结构

1. 物理层级：盘片 → 记录面 → 磁道（同心圆）→ 扇区（最小读写单元）→ 柱面（多盘片同半径磁道集合）
2. 硬盘总存取时间 = 寻道时间（磁头移动到目标磁道，耗时最长）+ 旋转等待时间（扇区转到磁头下）+ 读写时间（可忽略）
3. 磁盘调度算法（优化寻道时间）
    
```meraid
    
    |算法|规则|缺陷|
    |---|---|---|
    |FCFS 先来先服务|按请求顺序访问|寻道距离无优化，效率低|
    |SSTF 最短寻道优先|每次选距离当前磁头最近请求|远处请求饥饿，永久无法访问|
    |SCAN 电梯算法|沿单一方向走完所有请求再掉头|两端磁道等待久|
    |CSCAN 循环电梯|单向走完直接跳回起始端重新扫描|均匀分配访问延迟|
    
```

RAID10/01

1. RAID0 条带化：无冗余，多盘并行读写，速度最快；任意盘损坏数据全丢
2. RAID1 镜像：两两磁盘完全备份，容错强；磁盘利用率仅 50%
3. RAID2/3/4：海明校验 / 奇偶校验，商用极少
4. RAID5：奇偶校验条带分散在所有磁盘，允许坏 1 块盘；兼顾速度与存储利用率
5. RAID6：双份分布式奇偶校验，允许同时损坏 2 块盘
6. RAID10（1+0）：先镜像 RAID1，再条带 RAID0；RAID01 反之；兼顾容错与读写性能

### （四）Cache 高速缓存

1. 基础特性：CPU 私有、对程序员透明，存放主存热点副本，速度远高于内存
2. 三种地址映像方式
    
    - 直接映像：主存块固定映射 Cache 分区；硬件简单、易块冲突
    - 全相联映像：主存块可放入任意 Cache 块；冲突最少、硬件成本极高
    - 组相联映像：折中方案，分组内全相联、组间直接映射，工程最常用
    
3. Cache 替换算法：FIFO、LRU（最久未使用，考试高频）、LFU、OPT 最优置换
4. 写策略
    
    - 全写法（写透）：修改同时写 Cache + 主存，一致性强，速度慢
    - 回写法：仅写 Cache，淘汰时同步主存，速度快，存在数据不一致风险
    
5. 性能计算
    
    - 平均访问时间 = 命中率 ×Cache 访问时间 + (1 - 命中率)×(Cache + 主存访问时间)
    - 规律：Cache 容量越大，命中率上升，增速逐步放缓
    

### （五）网络存储

![[96e6ede62e7f351a-efe0d7fa0dbfd1f4~tplv-be4g95zd3a-448x448.jpeg|image]]

NAS/SAN结构对比

1. DAS 直连存储：硬盘直连服务器 SCSI 接口；扩展难、依赖服务器性能
2. NAS 网络附加存储：走 TCP/IP 以太网，提供文件级存储，独立存储头，不占用服务器算力
3. SAN 存储区域网络：专用光纤通道 FC/IP 存储网，块级存储，服务器与存储分离，高性能

### （六）虚拟存储

1. 核心：屏蔽物理磁盘差异，向上提供统一逻辑卷，应用无需关心物理存储位置
2. 分类
    
    - 拓扑：对称式（控制设备在数据通路）、非对称式（控制设备独立）
    - 原理：块虚拟（SAN）、文件虚拟（NAS）
    
3. 优势：简化扩容、统一管理、复用旧存储设备、降低上层应用存储开发成本

## 四、输入输出 I/O 系统

### 1. CPU 与外设 5 种数据传送方式

1. 无条件传送：外设永远就绪，无需状态检测
2. 程序查询：CPU 循环轮询外设状态，CPU 全程占用
3. 中断方式：外设就绪主动发中断，CPU 并行处理其他任务
4. DMA 直接存储器访问：DMAC 控制器接管总线，批量传输无需 CPU 逐字节干预
5. I/O 通道：独立硬件通道处理器，完全脱离 CPU 管控外设；分三类
    
    - 字节多路通道：分时低速字符设备（键盘、打印机）
    - 选择通道：独占通道高速块设备（磁带机）
    - 数组多路通道：分时多高速磁盘设备，兼顾速度与多路复用
    

### 2. 总线系统

1. 总线分类
    
    - 位置：片内总线、系统总线（板间）、机外总线（外设接口）
    - 功能：地址总线、数据总线、控制总线
    - 传输：并行总线（多位同时传，短距离）、串行总线（逐位传，远距离）
    
2. 总线带宽公式：带宽 = 数据位宽 / 总线周期
3. 典型外设接口：SATA、SCSI、USB、IDE、IEEE1394、eSATA、PCMCIA
4. I/O 端口编址
    
    - 独立编址：IO 地址与内存地址空间分离，专用 IO 读写指令
    - 统一编址：IO 端口映射进内存地址，通用内存读写指令访问
    

### 3. 串行通信

- 异步通信：每个字符加起止位，设备简单，传输效率低
- 同步通信：收发统一同步时钟，传输效率高，硬件复杂

## 五、指令系统

### 1. 指令基础

一条指令 = **操作码**（执行运算 / 控制）+ **地址码**（操作数位置）

执行流程：取指令 → 分析译码 → 执行运算

### 2. 寻址方式

1. 指令寻址：顺序寻址（PC 自增）、跳跃寻址（跳转指令修改 PC）
2. 操作数寻址
    
    - 立即寻址：地址段直接存操作数
    - 直接寻址：地址段为主存真实地址
    - 间接寻址：地址段指向存储单元，单元内才是操作数地址
    - 寄存器寻址：地址段为通用寄存器编号
    - 基址寻址：基址寄存器 + 形式地址，扩大寻址范围
    - 变址寻址：变址寄存器 + 形式地址，数组循环遍历常用
    

### 3. CISC 复杂指令集 vs RISC 精简指令集

表格

|特性|CISC|RISC|
|---|---|---|
|指令数量|多、长短不一|少、固定等长，单周期为主|
|内存操作|任意指令均可访问内存|仅 Load/Store 读写内存|
|控制方式|微程序控制|硬布线逻辑为主|
|寄存器|数量少|大量通用寄存器、寄存器窗口|
|流水线|难优化|天然适配流水线，搭配延迟转移解决断流|

## 六、多处理机系统（Flynn 分类 + 并行架构）

### 1. Flynn 计算机体系分类

1. SISD 单指令单数据流：普通单核计算机
2. SIMD 单指令多数据流：一条指令同步操作多组数据（GPU、向量处理器）
3. MISD 多指令单数据流：理论模型，无商用产品
4. MIMD 多指令多数据流：多核 CPU、分布式集群（软考多核计算机答案固定 MIMD）

### 2. 多处理机内存架构

![[212abe0edcc6192d-4869c04d123d1ff0~tplv-be4g95zd3a-448x448.jpeg|image]]

共享存储SMP

![[29048e8f66d0ffc2-5e2105cc90bfaaf0~tplv-be4g95zd3a-448x448.jpeg|image]]

COMA架构

![[eb2065121c6f20ec-255bf6b6ba6fa13c~tplv-be4g95zd3a-448x448.jpeg|image]]

S2MP分布式

1. 共享存储 SM（紧耦合 SMP/UMA）：所有 CPU 共用全局内存，访问速度均等；CPU 数量上限低（3~6 颗）
2. 分布式存储 LM（松耦合 MPP）：每个 CPU 自带本地内存，跨节点访问走互联网络，延迟更高；横向无限扩展
    
    - NUMA：分布式内存架构，本地内存快、远程内存慢
    - COMA：无物理主存，全节点缓存构成全局地址空间
    - S2MP：混合 NUMA 架构，存储带宽随 CPU 数量线性扩展
    
3. 互联网络：总线、交叉开关、多级网络，负责 CPU / 内存 / I/O 通信

## 七、计算机可靠性计算

### 1. 基础指标

- MTTF：平均无故障时间，故障率 λ=1/MTTF
- MTTR：平均修复时间，修复率 μ=1/MTTR
- MTBF 平均故障间隔 = MTTF + MTTR
- 系统可用性 = \(\frac{MTTF}{MTTF+MTTF} \times 100\%\)

### 2. 系统可靠度公式

1. **串联系统**：全部部件正常系统才正常
    
    \(R_{总}=R_1 \times R_2 \times ... \times R_n\)
2. **并联系统**：全部部件故障系统才故障
    
    \(R_{总}=1-(1-R_1)(1-R_2)...(1-R_n)\)
3. **N 模冗余**：奇数 N 个子系统 + 表决器，超过半数正常即可输出正确结果
4. **混合串并联**：分步计算，先算并联子系统可靠度，再代入串联公式整体求解
