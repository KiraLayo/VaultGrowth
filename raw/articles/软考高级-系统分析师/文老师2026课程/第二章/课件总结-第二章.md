这份文档是系统分析师软考操作系统专项讲义，整体分为**操作系统概述、进程管理、存储管理、设备管理、文件管理、作业与用户界面、国产操作系统**七大核心模块，配套大量考试考点、原理图与真题解题思路，下面分模块详细梳理：

## 一、操作系统概述

### 1. 核心作用与五大基础功能

1. **两大核心作用**
    
    - 资源管理，提升计算机整体运行效率；
    - 优化人机交互，提供友好操作接口。
    
2. **五大核心功能**
    
    ① 处理机管理（进程管理，程序运行以进程为最小单位）
    
    ② 存储管理（内存分配、虚拟存储、地址转换）
    
    ③ 设备管理（I/O 设备分配、缓冲、虚拟化）
    
    ④ 文件管理（文件存取、共享、权限、磁盘空间管理）
    
    ⑤ 作业与用户界面（作业调度、人机交互接口）
3. 新版教材改动点：新增进程通信、虚拟存储、文件安全保护、作业界面、国产操作系统；删除进程调度相关内容。

### 2. 操作系统分类

1. **批处理系统**：单道批处理、多道批处理（主机与外设并行工作）
2. **分时系统**：CPU 划分时间片，轮流服务多个终端用户
3. **实时系统**：对外界信息极速响应，可靠性要求极高，交互能力弱，用于工业控制、嵌入式设备
4. **网络操作系统**：实现联网设备资源共享，分客户 / 服务器、对等两种模式
5. **分布式操作系统**：多台分散计算机无主次之分，节点间自由通信协作
6. **嵌入式操作系统**
    
    - 特点：内存小、算力弱、低功耗、硬件可裁剪、高实时性、自带容错机制；
    - 初始化顺序：**片级初始化 → 板级初始化 → 系统初始化**（自底向上，硬件到软件）
    

## 二、进程管理（考试核心重难点）

### 1. 进程基础

1. **进程组成**：PCB（进程控制块，进程唯一标识）、程序段、运行数据；线程依附进程存在。
    
2. **进程状态转换**
    
    ![[e83efae9a531a6e0-08762ed67689c64d~tplv-be4g95zd3a-448x448.jpeg|image]]
    
    进程三态/五态转换图
    
    - 基础三态：就绪、运行、阻塞
        
        - 运行→就绪：时间片耗尽；就绪→运行：进程调度选中；
        - 运行→阻塞：等待 IO / 事件；阻塞→就绪：等待事件完成。
        
    - 扩展五态：新增**新建、终止**；新建进程先进入就绪队列，进程执行完毕进入终止态。
    
3. **前趋图**：描述任务并行、先后依赖关系，常结合 PV 操作出题。
    
4. **进程资源图**
    
    ![[048da280c573878e-5d7b9f8ac984f034~tplv-be4g95zd3a-448x448.jpeg|image]]
    
    进程资源图示例
    
    - 矩形 = 资源、圆形 = 进程；资源指向进程代表资源已分配，进程指向资源代表进程申请资源；
    - 阻塞节点：进程申请资源无剩余；全部进程阻塞则系统死锁；
    - 解题技巧：先释放非阻塞进程资源，回收后再判断剩余进程是否可运行。
    

### 2. 进程同步与互斥（PV 操作必考）

1. 基础概念
    
    - **临界资源**：同一时间仅允许一个进程访问的资源（打印机）；
    - **临界区**：进程中操作临界资源的代码片段；
    - **互斥**：独占访问临界资源，加锁解锁控制；
    - **同步**：多进程并发，存在执行先后等待关系，无独占资源限制。
    
2. PV 信号量操作
    
    ![[bb18f5a2bc3889a0-df466afeb57e5264~tplv-be4g95zd3a-448x448.jpeg|image]]
    
    P/V操作流程图
    
    - P 操作（申请资源）：`S=S-1`，S≥0 进程继续；S<0 进程阻塞，加入等待队列；
    - V 操作（释放资源）：`S=S+1`，S>0 进程继续；S≤0 唤醒队列中一个阻塞进程。
    
3. 经典模型：生产者消费者模型，通过空仓库、商品数量两类信号量控制同步互斥。
    
4. 前趋图 PV 解题规则：**箭头起点执行完执行 V，箭头终点执行前执行 P**，配套真题示例。
    

### 3. 进程间通信

- 低级通信：PV 信号量（仅传递简单信号）；
- 高级通信（大批量数据传输）：共享存储、消息传递、管道通信（pipe）。

### 4. 死锁

1. **死锁定义**：进程等待永远无法发生的事件，多进程互相等待资源形成循环阻塞。
2. 死锁四大必要条件（缺一不会死锁）
    
    资源互斥占有、占有并等待新资源、资源不可剥夺、进程资源图存在循环环路。
3. 死锁处理四大方案
    
    ① 预防：破坏四大条件之一，从根源杜绝死锁；
    
    ② 避免：银行家算法，分配前预判系统是否存在安全序列；
    
    ③ 检测：定时扫描系统，发现死锁再处理；
    
    ④ 解除：强制剥夺进程资源、撤销死锁进程。
4. 高频计算题
    
    - 死锁临界资源数：n 个进程，每个需 R 个资源，最坏死锁资源总数 = n*(R-1)，再多 1 个资源则不会死锁；
    - 信号量负数绝对值 = 当前等待该资源的进程数量。
    

### 5. 线程

1. 引入线程目的：进程创建、切换开销大，线程轻量化，提升系统并发度；
2. 进程与线程分工：
    
    - 进程：资源分配的独立单位；
    - 线程：CPU 调度执行的最小单位；
    
3. 线程资源特性：仅私有栈、寄存器、程序计数器；共享所属进程全部代码、全局变量、文件资源。

## 三、存储管理（地址转换、虚拟内存高频考点）

### 1. 分区存储管理（整块分配内存）

1. **固定分区**：内存预先划固定大小分区，存在**内部碎片**（分区剩余空间无法利用）；
2. **可变分区（动态分区）**：按需划分分区，无内部碎片，产生**外部碎片**；分配算法：首次适应、循环首次适应、最佳适应、最差适应；
3. **可重定位分区**：移动已分配分区合并碎片，解决外部碎片，仅内存不足时触发。

### 2. 分页存储管理

1. 逻辑地址拆分：页号 + 页内偏移；物理地址 = 物理块号 + 页内偏移，通过**页表**映射页号与块号；
2. 优缺点：内存利用率高、碎片极小；但页表增加系统开销，页面频繁置换会引发抖动；
3. 页面置换算法
    
    - OPT 最优置换（理论基准，淘汰未来最久不访问页面）；
    - FIFO 先进先出；LRU 最近最少使用（考试重点，性能最优）；LFU 最少访问；
    
4. 快表（TLB）：高速相联存储器，缓存高频页表项，加速地址转换；
5. 页表状态位：状态位（是否在内存）、访问位、修改位（判断置换优先级）。

### 3. 分段存储管理

![[343c39efc068d5d1-83d8dbbe12d42df6~tplv-be4g95zd3a-448x448.jpeg|image]]

分段地址转换图

1. 逻辑地址：段号 + 段内地址；段表存储**段基址、段长度**，访问前校验地址是否越界；
2. 优缺点：支持代码 / 数据共享、分段独立修改；内存碎片多，利用率低。

### 4. 段页式存储

![[1588138ca4d2e6e3-2611576f79b7928b~tplv-be4g95zd3a-448x448.jpeg|image]]

段页式地址转换图

1. 逻辑地址：段号 + 段内页号 + 页内偏移；先查段表，再查页表；
2. 优缺点：碎片少、易共享保护；双层查表，系统开销大、运行速度下降。

### 5. 虚拟存储管理

1. 核心思想：作业仅部分装入内存即可运行，剩余内容存磁盘，缺页时动态调入，逻辑扩容内存；
2. **抖动（颠簸）**：进程分配物理块过少，频繁缺页置换，CPU 利用率暴跌；解决方案：增加进程工作集内存块数量；
3. 虚拟存储两大核心功能：请求调入、页面置换；逻辑容量由内存 + 外存总和决定。

## 四、设备管理

1. **设备分类**
    
    - 数据组织：块设备（磁盘）、字符设备（键盘、打印机）；
    - 资源分配：独占设备、共享设备、虚拟设备；
    - 速率：低速、中速、高速设备。
    
2. 核心任务：记录设备状态、设备分配释放、缓冲区管理、I/O 中断处理。
    
3. **SPOOLING 虚拟设备技术**
    
    ![[94220c8cdef3d12e-0c11009514ddc073~tplv-be4g95zd3a-448x448.jpeg|image]]
    
    SPOOLING原理图
    
    - 解决独占设备利用率低问题，在磁盘开辟输入井、输出井；
    - 进程读写先存入磁盘缓冲区，外设空闲时统一处理，将物理独占设备虚拟为多台共享设备（典型：打印池）。
    
4. I/O 执行流程：用户程序发起请求 → 无关软件查缓存 → 驱动程序控制硬件 → 硬件完成触发中断 → 中断处理唤醒进程。
    

## 五、文件管理（索引结构、目录、磁盘空间管理必考）

### 1. 文件基础概念

- 文件：带文件名、有完整逻辑意义的信息集合；由**文件体（内容）+ FCB 文件控制块（管理信息）**组成；
- FCB 包含：基础信息（文件名、大小、地址）、存取权限、使用记录（访问时间、打开进程数）；所有 FCB 有序集合 = 文件目录。

### 2. 文件逻辑 / 物理结构

1. 逻辑结构：有结构记录式文件、无结构流式文件；
    
2. 物理存储结构：连续分配、链接分配、索引分配（重点）；
    
3. UNIX 多级索引结构
    
    ![[4c11ea36c9684c5c-2fe543d238dfad9e~tplv-be4g95zd3a-448x448.jpeg|image]]
    
    多级索引节点示意图
    
    - 索引节点：0~9 直接索引；10 一级间接、11 二级间接、12 三级间接；
    - 计算题核心：按块大小、地址项字节数，计算各级索引最大存储文件容量。
    

### 3. 文件目录与路径

![[9933dd8c758ff7c2-5ce642184ef74136~tplv-be4g95zd3a-448x448.jpeg|image]]

树形目录结构图

- 树形目录结构；
- 绝对路径：从根目录`/`开始完整路径；相对路径：从当前工作目录出发。

### 4. 磁盘空闲空间管理

1. 空闲表：记录连续空闲块，适合连续文件；
2. 位示图 Bitmap：每 1bit 标记一个磁盘块占用状态，高频计算题；
3. 空闲链表：空闲块通过指针串联；
4. 成组链接法：分组管理空闲块，每组首块记录下一组信息。

### 5. 文件共享与保护

1. 共享方式：硬链接、符号链接；
2. 存取保护方案：存取控制矩阵、存取控制表、用户权限表、文件加密；
3. 文件可靠性保障：转储恢复、日志记录、文件系统一致性校验（块、文件两层校验）。

## 六、作业与用户界面

### 1. 作业生命周期

![[22fefc462a2d8b8d-7b032736883f477e~tplv-be4g95zd3a-448x448.jpeg|image]]

作业状态流转图

状态流转：提交 → 收容（后备态，Spooling） → 执行（就绪 / 等待 / 运行） → 完成；

JCB 作业控制块是作业唯一标识，存储作业名、资源需求、状态。

### 2. 作业调度算法

先来先服务 FCFS、短作业优先、优先级调度、高响应比优先；

核心指标：响应时间、周转时间、带权周转时间。

### 3. 用户界面分类

控制面板界面、字符命令界面、图形 GUI、新一代多媒体 / 虚拟现实智能界面；分程序接口、图形接口两类软件接口。

## 七、国产操作系统（新增考点）

全部基于 Linux 内核，主流系统：

1. 麒麟 KylinOS：国产自主知识产权服务器 OS，分实时、安全、服务器版本；
2. Deepin 深度 Linux：面向桌面，适配笔记本、一体机；
3. UOS 统信操作系统：基于 deepin 开发，政企办公主流；
4. 其他：StartOS、欧拉 OS、龙蜥 OS 等，适配服务器、嵌入式、工业场景。
