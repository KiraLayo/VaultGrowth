# CRC 循环冗余校验码

## 特点

- 能检出错误（**任意多位**错都能检出），但**不能纠错**，也不能指出错了几位
- 收发双方使用**同一个生成多项式 G(x)**
- 实际应用：CRC32 等（编程中常用）

## 编码步骤（必考计算流程）

1. **约定生成多项式 G(x)**（题目给出），记最高次幂为 r
2. **补零**：原始信息后补 **r 个 0**，得到被除数
3. **取除数**：G(x) 各幂次存在记 1、不存在记 0，得到 r+1 位除数
   - 例：G(x) = x⁴ + x + 1 → 幂次 4、1、0 存在 → 除数 `10011`
4. **模 2 除法**（即异或运算，同 0 异 1；**不进位不借位**）：被除数 ÷ 除数，**商不重要，只看余数**；位数对齐即可除，不用管大小
5. **补位**：余数不足 r 位时，**左侧补 0** 凑足 r 位 → 这就是校验码
6. **拼接**：原始信息 + 校验码 = 最终发送串

**接收端校验**：完整编码再除以 G(x)，**余数为 0 无错，非 0 则有错**。

## 真题演练

> **真题**：数据信息 1100，生成多项式 G = x³ + x + 1（题目已给除数 `1011`），求 CRC 编码。

- 最高次幂 r = 3 → 补 3 个 0：被除数 `1100000`
- 模 2 除法求余数 → 余数 `10` → 不足 3 位，**左侧补 0** → 校验码 `010`
- 最终编码：`1100` + `010` = **`1100010`**（选 A）

> **课堂例题**：信息 `10110`、G = x⁴+x+1 → 除数 `10011` → 余数 `1111`（恰好 4 位）→ 发送串 `101101111`；若余数为 `11` 则补成 `0011`。

## 常见坑

- 余数补 0 是**补在左边**（高位），不是右边
- 模 2 除法**不看商**，只要位数对齐即可除
- r = 多项式最高次幂（如 x³ → r=3），校验位数量 = r，除数位数 = r+1
- 题目给"G=1011"时直接用，无需再从多项式推导
- 真题数据是 4 位 `1100`——字幕中"1100,1100"是千位分隔写法，勿误读为 8 位 `11001100`（位数对不上必错）
