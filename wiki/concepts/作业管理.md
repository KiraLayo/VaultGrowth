# 作业管理

> 第二版教材新增（新旧教材都没有考过），了解概念即可。**调度算法（FCFS/短作业/优先级）教材已删去展开讲述**，只保留响应比定义。

## 作业基础

- **作业** = 系统为完成一个用户计算任务所做的工作总和；组成 = **程序 + 数据 + 作业说明书**（进程只有程序+数据；说明书说明作业干什么、如何控制、含哪些资源）
- **作业步**：编辑 → 编译 → 链接 → 生成可执行代码 → 执行（每步一个作业步）
- 脱机：一次性提交作业说明书，之后不能控制；联机：人机交互实时输命令

## 作业状态流转

![[wiki/assets/作业状态流转图.jpeg]]
> 图：作业状态流转图（课件原图）

| 状态 | 含义 |
|------|------|
| 提交 | **正在**提交到外存（还没完全存进去） |
| 收容（后备） | **已完全**在外存，等待调度；后备队列 = **JCB 的排列**（不是作业本身） |
| 执行 | 被调度进内存分配资源运行，含就绪/运行/等待——**执行状态等同于进程状态**（作业被调度后就变成进程） |
| 完成 | 正常或异常结束 |

**JCB 作业控制块** = 作业唯一标志（类比 PCB），含用户名、作业名、状态标志等。

## 作业调度算法与指标

- 算法：FCFS 先来先服务、短作业优先、优先级、**响应比高优先**（响应比 = 响应时间 ÷ 执行时间，越高越优先）
- 核心指标：**周转时间 = 完成时刻 − 到达时刻**；**带权周转时间 = 周转时间 ÷ 运行时间**
- 口径：书上"响应时间=等待+执行时间之和"老师觉得奇怪（按理响应时间=等待被调度的时间），**考试按书上来**

## 用户界面

- 发展：控制面板式（开关/机械，嵌入式工业用）→ 字符命令界面（Linux/CMD）→ 图形 GUI → 新一代多媒体/虚拟现实智能界面（VR，未来方向）
- 软件接口分两类：**命令接口 + 程序接口**（给开发人员）、**图形界面接口**（给最终用户）
