# 分区存储管理

> 考得比较少，了解概念即可；**可变分区四算法教材已删除，但 2024 年 11 月考过，老师保留讲解（按扩展内容学）**。

## 三种分区方式

| 方式 | 做法 | 碎片 | 说明 |
|------|------|------|------|
| 固定分区 | 内存预先划成固定大小分区 | **内部碎片**（分区内剩余空间无法利用） | 例：8GB 切 100MB 分区，程序只要 50MB 也得占一个 100MB 分区，浪费 50MB |
| 可变分区（动态分区） | 按进程需求动态切割 | **外部碎片**（零碎小块无法分配给任何进程） | 例：切完 50MB/5MB/1MB 后剩 1MB 级小块无法用 |
| 可重定位分区 | 移动已分配分区使碎片合并成大块 | 解决外部碎片 | 仅内存不足时触发（开销大） |

## 可变分区分配算法（扩展内容）

| 算法 | 策略 |
|------|------|
| 首次适应 | 从地址 0 顺序找**第一个**能满足的空闲块 |
| 循环首次适应 | 不回头，从**上次分配位置之后**继续找 |
| 最佳适应 | 空闲块按大小升序找**第一个**能满足的（最接近） |
| 最差适应 | 取**最大**的空闲块 |

**实例**：已有作业 1/2/3 = 33K/22K/10K，空闲块 25K/28K/10K，新作业 9K：
- 首次适应 → 25K；最佳适应 → 10K（切 9K 剩 1K 变外部碎片）；最差适应 → 28K（剩 19K）；循环首次适应 → 从作业 3 之后找 → 28K
