# 国产操作系统

> 第二版教材**新增考点**，只给了基本定义没细节；老师个人估计"**几乎不会考**"——了解名称与定位即可。

## 主流系统

| 系统 | 定位 | 说明 |
|------|------|------|
| 麒麟 KylinOS | 国产自主知识产权**服务器** OS | 分实时、安全、服务器版本 |
| Deepin 深度 Linux | 桌面 | 面向笔记本、一体机 |
| **UOS 统信操作系统** | 政企办公主流 | 基于 deepin 开发 |
| StartOS / 欧拉 OS / 龙蜥 OS | 服务器、嵌入式、工业 | 华为欧拉、阿里龙蜥等 |

共同点：**全部基于 Linux 内核**。
