# 多处理机系统

第二版教材**新增**章节。定义：**两个或两个以上**处理机，在操作系统控制下**共享 IO 子系统**；基于 **MIMD** 结构。

## Flynn 体系分类（按指令流 / 数据流，重点）

> S=single 单、M=multi 多、I=instruction 指令、D=data 数据。中英对照要会。
> 结构规律：指令流由**控制部分**处理（多个指令流 → 多个控制部分）；数据流由**处理器**处理（多个数据流 → 多个处理器）；内存除 SISD 外均多个。

| 类型 | 含义 | 典型/特性 |
|------|------|----------|
| **SISD** | 单指令单数据流 | 单处理器系统（普通单核） |
| **SIMD** | 单指令多数据流 | 一条指令、多处理器**一步方式**执行同一条指令：并行/阵列处理机（**银河**巨型机，科学运算） |
| **MISD** | 多指令单数据流 | **被证明不可能**（多个领导指挥一个员工）——常考考点 |
| **MIMD** | 多指令多数据流 | 多核、多处理机系统（**主流**，四核八线程） |

**真题**：Flynn 按"执行程序过程中**指令流和数据流**的不同组合"分类；主流多核计算机属于 **MIMD**。

## 存储架构（宏观两分法）

| 架构 | 含义 | 耦合 | 规模 |
|------|------|------|------|
| 共享存储 SM（SMP） | 多处理机共享统一存储器（访问速度均等） | 紧耦合 | **CPU 数量上限低（3~6 颗）** |
| 分布式存储 LM | 每处理机有本地存储器，靠**网络/消息**通信 | 松耦合 | 跨节点访问延迟高，但**横向无限扩展** |

- **MPP**（海量并行处理）：纯分布式存储、大规模并行、消息机制通信——通信开销大、编程复杂
- **虚拟共享存储器 / 共享分布式存储**：物理上分布、逻辑上共享 = **存储虚拟化**思想（联系 [[wiki/concepts/虚拟存储]]）
- **SMP**（对称多处理机 = 共享存储多处理机）：基于共享存储、统一 shared memory

> 图：共享存储 SMP 架构（课件原图，图形考点）

### SMP 的三种模型变种

| 变种 | 特点 |
|------|------|
| **UMA** 均匀存储器存取 | 物理存储器被所有处理机**均匀共享**，访问速度一致 |
| **NUMA** 非均匀存储器存取 | 分布式内存架构：每处理机有自己的 Local Memory，访**本地快**、经网络访别人**慢** |
| **COMA** 只用高速缓存结构 | NUMA 的**特例**：把 Local Memory 换成 **Cache**（无物理主存，全节点缓存构成全局地址空间） |

![[wiki/assets/COMA架构图.jpeg]]

> 图：COMA 架构（课件原图）

**S2MP**：NUMA + COMA 结合——每个节点**既有 Cache 又有 Local Memory**（混合 NUMA 架构），存储带宽随 CPU 数量**线性扩展**。

![[wiki/assets/S2MP架构图.jpeg]]

> 图：S2MP 架构（课件原图）

> 记忆：UMA 均匀共享 / NUMA 有本地不快不慢 / COMA 用 Cache / S2MP 全都要。
> 宏观：MPP=分布式；SMP、S2MP=共享式（含变种）。

## 互连网络（并行处理系统核心）

| 方式 | 特点 |
|------|------|
| 总线 | **效率最低、征用（冲突）最严重**——同一时刻只有一台能用 |
| 交叉开关 | 冲突降到**最低**，但复杂性**最高** |
| 开关枢纽 | 由**仲裁单元**（决定谁用）和**开关单元**（完成连接）组成 |
| 多端口存储器 | 每个存储器模块多个存取端口，由**存储器**负责仲裁冲突 |
| 多级互连网络 | 了解即可 |
