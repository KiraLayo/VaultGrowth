# 指令系统

## 指令基础

- 一条指令 = **操作码**（执行什么动作）+ **地址码**（操作数在哪；可有多个操作数）
- 指令以二进制存放于主存
- 执行流程：取指令（地址来自 PC 程序计数器）→ 分析指令 → 执行指令（需要时再取操作数）

## 寻址方式（概念选择题）

**注意区分**：指令寻址是"找下一条指令"；操作数寻址是"找本条指令的操作数"。

### 指令寻址

- 顺序寻址：地址在 PC 中，一条接一条
- 跳跃寻址：地址由本条指令直接给出（如汇编跳转指令），修改 PC

### 操作数寻址（重点掌握前 5 种）

| 方式 | 地址码含义 | 特点 |
|------|-----------|------|
| 立即寻址 | 直接是**操作数本身** | 取指令即得数，**不访存** |
| 直接寻址 | 操作数在主存的地址 | 访存一次 |
| 间接寻址 | 存的是操作数地址的**地址** | **访存两次**（先取地址再取数） |
| 寄存器寻址 | 寄存器编号 | **速度最快**（操作数在寄存器） |
| 基址寻址 | 基址寄存器 + 形式地址 | 扩大寻址范围 |
| 变址寻址 | 变址寄存器 + 形式地址 | 数组遍历常用 |

> 基址/变址相对寻址等变种基本不考。

## CISC vs RISC（高频概念选择题）

> 中英对照历年直接考：**C = Complex 复杂、R = Reduced 精简**，别搞混。

| 维度 | CISC | RISC |
|------|------|------|
| 指令数量 | 多 | 少 |
| 长度 | 不固定（可变长） | 定长、单周期 |
| 使用频率 | 差别大（80-20 定律：20% 指令覆盖 80% 使用） | 接近 |
| 寻址方式 | 丰富（多） | 少（仅 Load/Store 访存） |
| 控制方式 | **微程序控制**技术 | **硬布线逻辑** + 流水线技术 |
| 寄存器 | 少 | **大量通用寄存器** |
| 特点 | 硬件复杂、执行周期长 | 适配流水线、效率高 |

**CISC 三大问题**：① 80-20 规律（指令使用频率不均衡）；② 复杂性给超大规模指令设计增加负担，**不利于单片集成**；③ 为支持目标程序优化增加复杂指令，以**增加硬件复杂度和执行周期**为代价。

**真题**：关于 CISC 叙述正确的是 D——"指令长度不固定，指令格式和寻址方式多"（复杂 = 多/长/可变/频率差别大）。

## RISC 流水线优化技术（解决跳转导致的断流）

| 技术 | 做法 |
|------|------|
| 延迟转移 | 跳转指令后**插入一条有效指令**，使转移被延迟执行 |
| 指令取消技术 | 转移/数据变换指令决定后续指令是否取消（相当于空操作，不影响流水线） |
| 重叠寄存器窗口 | 寄存器堆划窗口，与前一/后一过程**共用**（传参数与结果） |
| 指令流调整 | 流水线有断流可能时调整指令序列 |

> 流水线 = 取指→分析→执行重叠进行；跳转指令会中断流水线。第二版教材删了流水线计算题，但概念仍在。
