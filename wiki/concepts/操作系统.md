# 操作系统

## 核心思想

操作系统是计算机中最基本的**系统软件**（区别于应用软件），它管理整个计算机的**硬件和软件资源**。

两大核心作用：
1. **资源管理**：提高计算机系统的运行效率（不只是管理软件，也管理硬件）
2. **改善人机界面**：向用户提供友好的工作环境（早期 DOS/Linux 命令行 → 现代图形桌面）

> 定义本身不直接考，了解即可——注意"操作系统本身属于软件"这个定位（可能以概念题出现）。

## 四大特征（概念题）

| 特征 | 含义 | 备注 |
|------|------|------|
| 并发性 | 宏观上多程序同时推进，微观上 CPU **交替执行** | **并发 ≠ 并行**：并行=同一时刻真正同时运行（多核/多机）；并发只是宏观感觉（分时时间片 10ms 轮转，肉眼不可察） |
| 共享性 | 系统中资源可被多进程共享 | 与设备管理的虚拟化有关 |
| 虚拟性 | 独占设备可虚拟为共享设备 | 如 SPOOLING 技术 → [[wiki/concepts/设备管理]] |
| 不确定性（异步性） | 同一程序反复执行结果可能不同 | 中间有各种干扰 |

> 并行不是操作系统的特征——只有并发才是。**常考区分**。

## 五大功能（第二版教材改了口径）

| 功能 | 本质 | 说明 |
|------|------|------|
| 处理机管理（=进程管理） | 对 CPU 分配进行管理 | 程序运行以进程为最小单位，故称进程管理 |
| 存储管理 | 内存管理 | 分配、虚拟存储、地址转换 |
| 设备管理 | 外设管理 | I/O 分配、缓冲、虚拟化 |
| 文件管理 | 外存（硬盘空间）管理 | 存取、共享、权限、磁盘空间 |
| 用户界面（=作业管理） | 人机交互接口 | 旧教材叫"作业管理"，第二版改名 |

## 操作系统分类（常考）

| 类型 | 要点 |
|------|------|
| 批处理 | 无需人工干预，设定程序批量处理任务；单道（一次一个）/多道（同时多个，主机与外设并行） |
| 分时 | CPU 划分时间片轮流服务多终端；**交互能力强** |
| 实时 | 对外来信息快速响应（响应时限由**被控对象**规定）；**可靠性要求极高、交互能力弱**；工业控制、嵌入式 |
| 网络 | 联网设备资源共享；三种模式：集中式、C/S（客户端-服务器，最常用）、P2P 对等（各机平等，既可是客户端也可是服务器） |
| 分布式 | 网络操作系统的升级：多台分散计算机**无主次之分**，节点间自由通信协作 |
| 嵌入式 | 见下 |

## 嵌入式操作系统（常考）

特点：**微型化**（几兆~几十兆 vs Windows 几个 G）、**可定制**（针对不同硬件裁剪，缩短研发周期降低成本）、**高实时性**（不能像 PC 死机重启）、**高可靠性/安全性**、可移植。

**初始化顺序（考过）**：**片级初始化 → 板级初始化 → 系统初始化**（自底向上、硬件到软件）
- 片级 = 芯片级（CPU 类芯片初始化）；板级 = 板卡上各种外设；系统级 = 操作系统/BIOS 固化引导程序
- 类比 PC 启动：硬件 → BIOS → OS
