# 数据库系统概述

## 基本概念（了解即可）

- **数据**：描述事物的符号记录；计算机中分三类——文本、图形图像、音频视频
- **DB 数据库**：长期存储、有组织、可共享的数据集合；特征：按数据模型组织、多用户共享、冗余度小（靠规范化）、独立性高、易扩展
- **DBS 数据库系统**：四大组成 = DB + 硬件 + 软件（OS+DBMS+应用）+ 人员（DBA、设计员、程序员、终端用户）
- **DBMS 数据库管理系统**：核心软件；数据定义、数据操作、数据运行管理；开发人员接触最多的是 SQL

## 三级模式两层映像（必考）

![[wiki/assets/数据库三级模式两层映像图.jpeg]]

> 图：三级模式与两层映像（课件原图）

| 模式 | 面向 | 对应物 |
|------|------|--------|
| **外模式** | 用户/应用程序 | 视图 |
| **概念模式（模式）** | 全局逻辑结构 | 基本表 |
| **内模式** | 物理存储 | 存储文件 |

- 越往上越逻辑（用户相关），越往下越物理（存储相关）
- **外模式↔概念模式映像**：表结构修改时只需改此映射 → **逻辑独立性**
- **概念模式↔内模式映像**：物理存储修改时只需改此映射 → **物理独立性**
- 视图是**假表**：对视图修改不影响真正的表

## 真题演练

> **真题**：数据库视图、基本表和存储文件的结构分别对应什么？物理/逻辑独立性分别通过修改什么完成？

- 视图→外模式；基本表→概念模式；存储文件→内模式
- 物理独立性 = 改**概念模式与内模式之间的映像**（看到"物理"就联想到内模式）
- 逻辑独立性 = 改**外模式与概念模式之间的映像**
- **不存在外模式直接与内模式的映像**——不能跨越层次，相邻层才有映射

## 常见坑

- 外模式与内模式之间**没有直接映像**（最易错）
- 视图是假表，改视图不影响表
- "物理"字眼 → 内模式；"逻辑"字眼 → 概念模式/映像
