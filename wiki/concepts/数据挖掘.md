# 数据挖掘

> 第二版新增、必考选择题（**给定义选方法，抓关键词**）。定义：发现**违背直觉**的信息或知识——"挖掘出的信息越是出乎意料，就越可能是有价值的"（啤酒和尿布）。

## 体系结构（图）

![[wiki/assets/数据挖掘体系结构图.jpeg]]

> 图：数据挖掘体系结构（课件原图）

- **纵向两个工具**：知识发现系统管理器 + 知识库
- **横向五个步骤**：数据访问接口 → 数据选择 → 知识发现 → 发现评价 → 发现描述（保存结果 + 支持 **DSS 决策支持系统**）

## 完整流程

**问题定义 → 建立数据挖掘库（数仓）→ 分析/调整数据 → 模型化（核心环节）→ 评价和解释**

## 常用技术 12 种（必考选择题，抓关键词）

| 技术 | 关键词 |
|------|--------|
| 决策树 | 最大信息量的属性、树节点 |
| 分类 | 按含义划分组 |
| 粗糙集 | **不精确**概念、上/下近似 |
| 神经网络 | 神经元、模式建模 |
| 关联规则 | 重复出现概率高、关联性强 |
| 概念树 | 抽象、**层次结构** |
| 遗传算法 | 模拟**生物进化**（繁殖/交叉/变异） |
| 依赖性分析 | 对象变化带动另一个 |
| 公式发现 | 工程/科学库、**数学运算** |
| 统计分析 | 函数关系（确定性）/相关关系（不确定） |
| 模糊论 | 模糊集合、不确定性 |
| 可视化 | 图形化展现 |

## 分析方法 6 种（与技术清单区分）

1. **关联分析**：不同事件间的关联性
2. **序列分析（时序分析）**：一定时间间隔内接连发生的事件（构成序列）
3. **分类**：先有标记再分类（**离散**变量）
4. **聚类**：分类的**逆过程**——先分类再提炼标记（物以类聚）
5. **预测**：同分类但预测**连续**变量
6. **时间序列分析**：随时间变化的序列，预测未来/周期趋势（与序列分析区分：一个=事件集合，一个=随时间变化）

## 常见坑

- **分类 vs 聚类**：分类先有标记；聚类先分类再提炼标记（逆过程）
- **分类 vs 预测**：分类分离散变量；预测连续变量
- **序列 vs 时间序列**：序列=一定时间内的所有事件；时间序列=随时间变化、预测趋势
- **公式发现 vs 统计**：公式=数学运算；统计=函数/相关关系——别搞混
