# 数据模型

## 分类（五大类，以课件为准）

| 模型 | 特点 |
|------|------|
| **概念模型（E-R）** | 用户视角，现实世界→信息世界的第一层抽象；图形 |
| **层次模型** | 树形结构 |
| **网状模型** | 多对多网状，一个事物与多个事物都有联系 |
| **关系模型** | 二维表，外键表达联系；数学基础严谨、简单透明、独立性高；缺点：查询效率低于非关系模型 |
| **面向对象模型** | 以对象为单位，属性+方法，支持类/继承 |

- 主流数据库（MySQL、SQL Server、Oracle）均为**关系模型**
- 概念模型不绑定具体 DBMS；**逻辑模型（关系/网状/层次/面向对象）绑定 DBMS**
- 关系模型：行=元组（水平记录），列=属性

## 三要素（考过，要记）

1. **数据结构**：所研究对象类型的集合（数据怎么组织）
2. **数据操作**：对数据的基本操作——**增删改查**
3. **完整性约束**：约束数据的规则（如年龄不能 800 岁）
