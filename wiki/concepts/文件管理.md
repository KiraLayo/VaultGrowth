# 文件管理

> 必考计算集中在：**UNIX 多级索引容量**、**位示图**；常考概念：树形目录路径。

## 文件与 FCB

- 文件 = **文件体（内容）+ FCB 文件控制块（管理信息）**；带文件名、有完整逻辑意义的信息集合（exe/dll 都是文件；病毒是代码不是文件）
- FCB 含：基础信息（文件名、大小、地址）、存取权限、使用记录（访问时间、打开进程数）
- **所有 FCB 的有序集合 = 文件目录**
- 逻辑结构：有结构记录式文件（记录=有完整逻辑意义的一段）、无结构流式文件（比特流）
- 物理结构：连续分配、链接分配、索引分配（重点）

## UNIX 多级索引（必考计算，2 分）

![[wiki/assets/UNIX多级索引节点图.jpeg]]
> 图：多级索引节点示意图（课件原图）

- 13 个索引节点（0~12）：**0-9 直接索引、10 一级间接、11 二级间接、12 三级间接**
- **核心公式：每级指针数 = 盘块大小 ÷ 地址项字节数**（如 4KB/4B → 1024 个；索引级别按 1024 递增）
- 算指针数用**索引块大小**；算文件长度用**数据块大小**
- **考试最多考到二级**（三级原理相同）
- 常见坑：默认**从 0 开始编号**（题目明说从 1/3 开始才按题目）；闭区间计数（516-5=511，加 1 才是 512 个块，故 5~516 覆盖 512 块）；**不能带计算器，要动手算**

## 树形目录与路径（常考，简单）

![[wiki/assets/树形目录结构图.jpeg]]
> 图：树形目录结构图（课件原图）

- **绝对路径**：从根目录 `/` 开始的完整路径，**开头的 "/" 不能省略**
- **相对路径**：从当前工作目录出发，**无前导杠**
- **全文件名 = 绝对路径 + 文件名**（路径本身不含文件名）
- 路径末尾的杠**可加可不加**（建议加，规范）

## 位示图（必考计算）

- 每 **1 bit** 标记一个磁盘块：0=空闲、1=占用；位示图总位数 = 物理块总数
- 块号 → 字号：块号 ÷ 字长，商 = 所在字（数量第 N 个）；**从 0 编号则编号 = 数量 - 1**
- 单位注意：存储计量按 **1024** 换算（其他场景按 1000）

## 磁盘空闲空间管理

| 方法 | 原理 | 适用 |
|------|------|------|
| 空闲表 | 记录"起始空闲块号+空闲块数" | 适合连续文件 |
| 位示图 | 每物理块 1 bit | **最重要，会考计算** |
| 空闲链表 | 空闲块指针串联 | 简单 |
| 成组链接法 | 每 100 块一组，组首块登记下一组盘块号 | 空闲链表的改进（指针少） |

## 文件共享与保护

- **共享**：不同用户进程使用同一文件；文件名与文件说明分离利于共享
- 硬链接：基于索引节点（两个文件目录项指向同一索引节点）
- 符号链接：建立新文件映射原路径 = **快捷方式**
- 存取保护：**存取控制矩阵**（行=用户、列=文件，完整但空项多浪费大）→ 分解为**存取控制表**（按列/以文件为单位）与**用户权限表**（按行/以用户为单位）；另有**文件加密**（存时加密用时解密）
- 可靠性：转储恢复（备份）、日志文件（按日志恢复）、文件系统一致性检查（哈希/完整性）——安全可靠在信息安全章详讲

## 真题演练

**真题 1：UNIX 多级索引容量（重点 2 分）**
> 索引节点 8 个地址项（4B/项）：5 个直接 + 2 个一级间接 + 1 个二级间接；索引块和数据块均 1KB。问：①逻辑块 5、518 各用什么索引？②文件最大长度？

- ① 块 **5 → 一级间接**（5 个直接覆盖 0-4）；块 **518 → 二级间接**（一级间接覆盖 5-516，二级从 517 起）
- ② 最大 = 5×1KB + 2×256×1KB + 1×256×256×1KB = 5 + 512 + 65536 = **66053KB**
- "这个题你会做，这两分就很容易拿到了"；历年基本就这么考

**真题 2：树形目录路径**
> 当前工作目录 sw\shell，访问 fort.swf（位于 sw/shell/flash/ 下）

- 全文件名 **选 D**：/sw/shell/flash/fort.swf（前导杠不能省、漏层级的不选）
- 相对路径 **选 B**：flash/（无前导杠）

**真题 3：位示图计算**
> 字长 32 位、物理块 4MB、物理块和字均从 0 编号。①16385 号块在第几个字？②磁盘 1000GB 需多少个字？

- ① **第 512 个字**：16385÷32 = 商 512 余 1 → 数量上第 513 个字，但从 0 编号 → 编号 512（"加 1 减 1 的问题"）
- ② **8000 个字**：1000GB÷4MB = 250×1024 块（1024 换算）÷ 32 = 8000
- 老师："出得非常仁慈，若同时给 512/513 两个答案，估计很多人都要栽了——513 是错的"
