# 计算机系统层次结构

## 核心结构（第二版教材新增考点）

自上而下三层：

1. **应用层**：应用软件（面向用户业务）
2. **系统层**（系统软件）：语言处理程序 + 操作系统
3. **硬件层**（裸机）：机器指令语言 → 微指令系统 → 硬联逻辑

![[wiki/assets/层次结构图.jpeg]]

> 图：计算机系统层次图（课件原图，图形考点）

**填空考点**：硬件层由门电路、触发器构成，分**微程序级**（微指令）与**传统机器级**（机器指令）；系统层中操作系统管理硬件资源、语言处理程序做代码翻译。

记忆要点：硬件层内部从下到上是「电路 → 微指令 → 机器指令」，一条指令由多条微指令组成；机器指令是计算机能识别的 0/1 字符串。

## 冯·诺依曼五大部件

| 部件 | 功能 |
|------|------|
| 运算器 | 所有算术运算（加减乘除）与逻辑运算（与或非） |
| 控制器 | 指令控制、时序控制、电路控制——**核心中的核心**，计算机的大脑 |
| 存储器 | 内存（易失、快、小）+ 外存（持久、慢、大） |
| 输入设备 | 鼠标、键盘、手写板、麦克风 |
| 输出设备 | 显示器、打印机、投屏 |

- CPU = 运算器 + 控制器（CPU 是硬件系统核心，控制器是 CPU 核心 → 核心中的核心）
- 输入输出设备统称**外设**（I/O = Input/Output）

## 软件分类

**系统软件**（五大类，管理/调度/监视/服务计算机系统）：
1. 操作系统
2. 语言处理程序（编译、汇编、解释——把高级/汇编语言翻译为机器语言）
3. 服务性程序
4. 数据库管理系统 DBMS
5. 计算机网络软件

**应用软件**：解决特定应用问题的软件（地图、影音等），种类繁多。

**固件（Firmware）**：固化在永久保存器件（EPROM/EEPROM 可编程可擦写只读存储器）中的程序，如 BIOS、嵌入式烧写程序——「具有软件功能的硬件」，要点是**固化**。

> 易错点：DBMS、网络软件属于**系统软件**而非应用软件。
