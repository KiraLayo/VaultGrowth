# 设备管理

## 设备分类

| 分法 | 类别 |
|------|------|
| 按数据组织 | **块设备**（一次传一块数据=很多字节，高速，如磁盘）、**字符设备**（按字符/比特流/字节传输，如键盘、打印机） |
| 按功能 | 输入、输出、存储、联网、供电设备 |
| 按资源分配 | **独占**（互斥硬件资源，同一时刻只能一个进程用）、**共享**、**虚拟**（独占→虚拟共享，靠 SPOOLING） |
| 按传输速率 | 低速、中速、高速 |

## IO 软件分层（重要考点，考过好几次）

> 考法：给出层次图挖掉**中间三层**（最上面用户进程、最下面硬件不用挖），问是哪些层。

从上到下**越来越与硬件相关**：

1. **用户进程**：发出 IO 调用（读外设数据请求）
2. **设备无关软件**：命名、保护、阻塞、缓冲分配；**先检查高速缓冲/内存里有没有要读的数据块**，有直接给、没有才继续——记住"**无关**"二字，到这里还没碰硬件
3. **设备驱动程序**：与具体硬件相关（不同设备不同驱动）；向 IO 硬件发请求，用户进程等待磁盘操作
4. **中断处理程序**：硬件完成产生中断后转入；检查中断原因、确认读取完成、唤醒用户进程取回信息

**读磁盘实例流程**：用户进程发 IO 调用 → 设备无关软件查缓存（有→直接返回）→ 调设备驱动程序向 IO 硬件发请求 → 用户进程等待 → 磁盘传送完成产生中断 → 中断处理程序检查原因 → 唤醒用户进程取数据 → IO 结束。

## SPOOLING 虚拟设备技术

![[wiki/assets/SPOOLING原理图.jpeg]]
> 图：SPOOLING 原理图（课件原图）

- 解决**独占设备利用率低**（如打印机：别人用时你提交会提示"打印机忙，请稍后再来"，且不知道何时用完）
- 在磁盘上开辟**输入井、输出井**（两个缓冲区）：所有人的请求**按顺序排队**，提交**总能成功**，打完一个打下一个
- 效果：把物理独占设备**虚拟为多台共享设备**（典型：打印池）；宏观上大家"同时"用同一台打印机
- 类比 CPU 分时调度：10ms 跑 QQ、10ms 跑微信，微观串行宏观并发
- **注意**：共享≠打印机变成两台同时用，而是"随时提交、排队打印"

## 真题演练

**真题：IO 软件叙述**
> "IO 软件**开放了** IO 操作实现的细节，方便用户使用 IO 设备"

- 答案：**该说法错误**。分层的目的就是**隐藏/屏蔽**底层硬件细节；IO 软件方便用户使用设备，但不是"开放细节"、也不直接提供物理接口（物理接口在底层做掉）
