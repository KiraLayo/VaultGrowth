# 输入输出系统

第二版教材**新增**章节。IO 系统 = IO 设备 + IO 接口 + IO 控制管理软件。

## CPU 与外设的数据传送方式（五种，递进关系）

| 方式 | 机制 | CPU 与设备 | 特点 |
|------|------|-----------|------|
| 程序控制 | 无条件传送 / 程序查询（while 循环轮询） | **串行** | 效率极低，已淘汰 |

> 口径说明：课件把「程序控制」拆为两项——**无条件传送**（外设永远就绪，无需状态检测）与**程序查询**（CPU 循环轮询），合计仍为五种。
| 中断 | 设备完成后发中断请求，CPU 响应 | 并行 | 普遍采用；CPU 参与仍多 |
| DMA | 直接主存存取：主存与外存间架设数据通路，**DMAC 控制** | 并行 | CPU 仅做初始化，后续全由 DMAC 完成 |
| 通道 | 独立硬件通道，**统一管理多路外设**（多个 DMA 控制器） | 并行 | 比 DMA 先进 |
| IO 处理机 | 具有**独立指令系统和中断系统**，相当于小型计算机 | 并行 | 最先进，专用大型高效数据传输 |

**中断五阶段**：提出中断请求 → 中断判优（多个同时来，优先级高的先响应）→ 响应 → 调中断处理程序 → 返回。

**通道三类**：字节多路通道（**低速**设备：键盘、打印机）、选择通道（**高速**设备：磁带机）、数组多路通道（二者结合，磁盘）。

## 总线系统

**定义**：设备之间传输信息的公共数据通道。分类四个维度：

| 维度 | 分类 |
|------|------|
| 按功能 | 地址总线（宽度决定寻址空间：32 位 → 2³²=4G）、数据总线（并行传输位数）、控制总线 |
| 按位置 | 片内总线、机内（系统）总线、机外总线（USB/网口/串口并口） |
| 按功用 | 局部总线（片内与系统总线之间，ISA 板级）、系统总线（PCI/ISA）、通信总线（机外） |
| 按数据线 | 并行（多线同时传，效率高成本高，**短距离**）、串行（单线逐位，效率低成本低，**长距离**） |

**性能指标 5 个**：宽度（线数）、带宽（最大传输速率）、负载（可接最大设备数）、分时复用、突发传送（一个总线周期内传输**地址连续的多个数据**）。

### 带宽计算（计算题）

$$\text{总线带宽} = \frac{\text{传输数据量}}{\text{传输时间}} = \frac{\text{数据线位数} \times \text{时钟频率}}{\text{总线周期时钟数}}$$

课件简化式：带宽 = 数据位宽 ÷ 总线周期（同一公式的不同写法）。

**真题**：10MHz、1 总线周期 = 2 时钟周期、并行传 4B → 时钟周期 = 1/10⁷ s，总线周期 = 2×10⁻⁷ s → 带宽 = 4B ÷ 2×10⁻⁷s = **20MB/s**。

## IO 接口与端口

- **IO 接口 = IO 控制器**：主机与外设之间的界面；功能：地址译码、设备选择、数据缓冲、数据格式变换、通信
- **IO 端口本质 = 接口电路中可被 CPU 直接访问的寄存器**
- **编址方式**：
  - 独立编址：端口与主存地址空间**分开**，用专用 IO 指令（IN/OUT）
  - 统一编址（存储器映射）：端口与主存**统一编址**，用同一套指令访问

## 串行通信与常见接口

- 异步通信：每字符加**起止位**，设备简单、效率低（如发短信）
- 同步通信：收发共享**同步时钟**，只需起始同步字符，效率高（如打电话）
- 接口：IDE/ATA-7、**SATA**（支持热插拔的串行接口，24 年考过）、eSATA、SCSI、IEEE1394、USB（1.0/2.0/3.0）、PCMCIA

## 常见坑

- 五种方式是**递进**的：中断比程序控制好、DMA 比中断好、通道比 DMA 好、IO 处理机最好
- 通道的关键特性是**统一管理**多路外设，不是更快
- 地址总线宽度决定可寻址内存大小（32 位 → 4G）
- 串行适合长距离、并行适合短距离——别记反
