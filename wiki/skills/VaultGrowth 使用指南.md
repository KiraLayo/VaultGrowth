# VaultGrowth 使用指南

## 核心一句话

**学习时把素材丢进 `raw/`，说「ingest」——剩下的（建页、链接、索引、复习提示）交给助手完成。**

## 五种使用场景

### 1. 学习 → 摄入（ingest）

学完一节/一章后，把素材丢进 `raw/` 对应目录：

| 素材 | 位置 |
|------|------|
| 视频课程课件/字幕 | `raw/articles/软考高级-系统分析师/文老师2026课程/` |
| 文章/博客/剪藏 | `raw/articles/` |
| 书/章节摘要 | `raw/books/` |
| 播客/视频/杂项 | `raw/other/` |

然后说「ingest」。助手的处理流程：

1. 先说明摄入范围与粒度，**等你确认后再动手**（这是本库的铁律）
2. 课件为骨架建页、字幕为补充；从视频中提取真题进概念页「真题演练」块
3. 计算/记忆类考点标记 `mastery: 待复习`
4. 更新 [[index]] 与 [[log]]

### 2. 复习 → review

说「复习」→ 助手从 [[index]] 挑选 `种子`/`成长中` 页面出题考你：

- 计算题考点（CRC、海明码、Cache、磁盘调度、可靠性、总线带宽）**遮答案重做**
- 做错的补进页面「常见坑」
- 通过后 `mastery` 从 `待复习` 更新为 `已掌握`

### 3. 提问 → query

直接提问，例如"海明码校验位怎么数？"→ 助手读相关页面，给带 `[[引用]]` 的答案。值得留存的问答可归档为综合页/概念页/日志。

### 4. 维护 → lint

说「检查 wiki」→ 体检：矛盾、孤儿页、重复概念、种子债、跨版本断言冲突（"已删除不再考"类）。

### 5. 反思 → journal

每周复盘、里程碑、顿悟 → 助手建 `wiki/journal/YYYY-MM-DD 主题.md`。这是你的空间，助手只串联结构，内容以你的声音为准。

## 浏览路径

1. Obsidian 打开 **VaultGrowth** 库
2. 从 **[[index]]** 进（全库索引，🌱种子/🌿成长中/🌳成熟）或 [[log]] 看历史
3. **图视图（Graph View）**看知识连接——本库的灵魂
4. 备考入口：[[wiki/syntheses/软考系统分析师-计算机系统章节学习路线]] · [[wiki/syntheses/软考系统分析师-操作系统章节学习路线]] · [[wiki/syntheses/软考系统分析师-数据库章节学习路线]]（真题索引 + 进度面板）

## 快速开始（3 步）

1. 学完一个章节 → 素材丢进 `raw/`
2. 说「ingest」
3. 确认范围 → 等页面建好 → 从学习路线页开始复习
