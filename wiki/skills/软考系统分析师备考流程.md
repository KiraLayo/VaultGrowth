# 软考系统分析师备考流程

## 学习顺序（依据课程设计）

1. **导学**：了解考试结构、教材对应关系
2. **第一章节 计算机系统**（对应教材 3.1–3.5）→ ✅ 已完成摄入
3. **操作系统**（3.6 单独成章，内容多）→ ✅ 已完成摄入
4. **计算机网络与分布式系统** → 下一步（校验码、可靠性等已在一章提前讲过）
5. **数学与工程能力**（线性规划等）放最后——先打基础再刷数学题

> 第二版教材：第一章绪论不考，无需看；课后习题遇到**数据表示范围、流水线计算**等已删考点直接跳过。

## 三类考点应对策略

### 计算题（需要动手算，已标 mastery: 待复习）

| 考点           | 对应页面                        | 掌握程度       |
| ------------ | --------------------------- | ---------- |
| CRC 校验码      | [[wiki/concepts/CRC循环冗余校验]] | 会算真题       |
| 海明码（位数/校验关系） | [[wiki/concepts/海明码]]       | 会算位数，理解原理  |
| Cache 平均访问时间 | [[wiki/concepts/Cache高速缓存]] | 记公式套用      |
| 磁盘调度 / 存取时间  | [[wiki/concepts/磁盘存储]]      | 会算寻道序列     |
| 系统可靠性        | [[wiki/concepts/系统可靠性]]     | 串联/并联/混合公式 |
| 总线带宽         | [[wiki/concepts/输入输出系统]]    | 数据量÷时间     |

### 概念选择题（记区别）

层次结构、RAID 各级、CISC/RISC、Flynn 分类、NAS/SAN、I/O 传送方式、寻址方式、Cache 映像/替换/写策略、总线分类。

### 图形考点（认图）

分层结构图、磁盘物理结构、RAID 示意图、Cache 映像、多处理机存储模型、可靠性结构框图。

## 复习节奏建议

- 每节视频 → 素材丢入 `raw/` → 章节批次摄入（课件为骨架 + 字幕为补充，真题提取进概念页真题演练块）
- 复习时对计算题页**遮住答案重做**，做错的补进「常见坑」
- 每周对照章节学习路线勾选进度：[[wiki/syntheses/软考系统分析师-计算机系统章节学习路线]] · [[wiki/syntheses/软考系统分析师-操作系统章节学习路线]]
- 复习通过后将 `mastery: 待复习` 更新为 `已掌握`
