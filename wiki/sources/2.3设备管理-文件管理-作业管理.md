## 内容结构

1. **设备管理概述**：设备=输入/输出设备（IO 设备）；IO 系统=设备+控制器+通道+总线+IO 软件（通道概念不考）；四类分法：按数据组织（块设备一次一块/字符设备按字符）、按功能（输入/输出/存储/联网/供电）、按资源分配（独占/共享/虚拟）、按速率
2. **IO 软件分层（重要考点，考过好几次，挖空考中间三层）**：用户进程（发 IO 调用）→ 设备无关软件（命名/保护/阻塞/缓冲分配，**先查缓存有数据直接给**，"无关"=还没到硬件）→ 设备驱动程序（与具体硬件相关）→ 中断处理程序（检查中断原因、唤醒进程）→ 硬件。读磁盘实例流程完整走一遍
3. **SPOOLING 虚拟设备**：独占设备（打印机忙就拒绝）→ 磁盘上开**输入井、输出井**（两个缓冲区），所有人请求排队、提交总能成功，宏观上"同时"用一台打印机（类比 CPU 分时：10ms QQ/10ms 微信）；**共享≠打印机变两台**，而是随时提交排队打印
4. **文件管理概述**（不怎么考）：文件=文件体+FCB；FCB 含基础信息/存取权限/使用记录；FCB 有序集合=文件目录；逻辑结构（记录式/流式）、物理结构（连续/链接/索引）
5. **UNIX 多级索引（历年就这么考，2 分）**：13 个索引节点 0-12；0-9 直接、10 一级间接、11 二级、12 三级；**每级指针数=盘块大小÷地址项字节数**（4KB/4B→1024 个，按 1024 递增）；索引块算指针数、数据块算文件长度；**考试最多考到二级**
6. **树形目录（重点，简单）**：绝对路径开头" / "不能省略、路径末尾杠可加可不加；相对路径无前导杠；全文件名=绝对路径+文件名（路径不含文件名）
7. **磁盘空闲空间（位示图最重要）**：空闲区表（适合连续文件）、位示图（每物理块 1 bit，0 空 1 占）、空闲链表、成组链接法（每 100 块一组，组首块登记下一组盘块号）
8. **文件共享与保护**：共享=不同用户进程用同一文件；硬链接=基于索引节点（两个目录项指同一节点）、符号链接=快捷方式；存取控制矩阵（行=用户列=文件，完整但浪费）→ 分解为存取控制表（按列/以文件为单位）/用户权限表（按行/以用户为单位）、密码（加密存取）；可靠性：转储恢复、日志文件、一致性检查（哈希）；安全可靠后面信息安全章详讲
9. **作业管理（新考点但没考过）**：作业=程序+数据+作业说明书；作业步（编辑→编译→链接→执行）；脱机/联机；状态流转：提交（正在写外存）→收容/后备（已完全在外存等调度，**后备队列=JCB 的排列**）→执行（=进程状态）→完成；JCB=作业唯一标志（类比 PCB，含用户名/作业名/状态标志）
10. **作业调度**：FCFS、短作业优先、优先级、响应比高优先（响应比=响应时间÷执行时间）；书上删去了前三种的展开讲述；核心指标周转时间/带权周转时间
11. **用户界面**：发展=控制面板式→字符命令→图形 GUI→新一代（VR）；接口=命令接口+程序接口（给开发者）+图形界面接口（给最终用户）
12. **国产 OS（新增但老师估计几乎不考）**：全部基于 Linux 内核：麒麟（服务器，实时/安全/服务器版）、Deepin（桌面）、UOS 统信（基于 deepin，政企主流）、StartOS/欧拉/龙蜥

## 真题演练（本课内嵌 4 道）

1. **IO 软件叙述题**：选项"IO 软件**开放了** IO 操作实现的细节" → **错**；分层目的是**隐藏/屏蔽**底层硬件细节（"开放"必错）
2. **UNIX 多级索引（2 分重点题）**：8 个地址项（4B/项）：5 直接+2 一级间接+1 二级间接；盘块 1KB → 逻辑块 5 → **一级间接**（直接覆盖 0-4）；块 518 → **二级间接**（一级覆盖 5-516）；最大长度 = 5×1KB + 512×1KB + 256×256×1KB = **66053KB**。坑：默认从 0 编号；闭区间计数 516-5 要 +1；**不能带计算器、动手算**
3. **树形目录**：当前目录 sw\shell，访问 fort.swf → 全文件名 **选 D**（/sw/shell/flash/fort.swf，前导杠不能省）；相对路径 **选 B**（flash/，无前导杠）
4. **位示图**：字长 32 位、物理块 4MB、从 0 编号 → ①16385 号块在**第 512 个字**（16385÷32 商 512 余 1，从 0 编号故 512 不是 513）；②磁盘 1000GB → **8000 个字**（250×1024 块 ÷32）。坑：存储单位按 1024（非 1000）；"出得非常仁慈，若同时给 512/513 很多人要栽"

## 口径说明

- **响应比定义**：书上"响应时间=等待+执行时间之和"老师觉得奇怪（按理响应时间=等待被调度时间），**"你按照书上来"**（响应比=响应时间÷执行时间）
- **作业调度算法**：新版教材删去 FCFS/短作业/优先级的展开讲述（与删除进程调度同源），只保留响应比定义
- **可靠性细节**：课件总结"块、文件两层校验"视频未提，只讲转储/日志/一致性检查（哈希）——后面信息安全章详讲
- **收容/后备**：提交=正在写外存（没完全存进去），后备=已完全在外存等待调度（课件总结与 SPOOLING 关联，视频未关联）
- **国产 OS**：课件总结列"新增考点"，老师个人估计"**几乎不会考**"——了解名称即可
- 全章小结：操作系统选择题**约 6 分**；课后习题即历年真题，都在新老教材范围内
